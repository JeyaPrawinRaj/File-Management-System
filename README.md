# 📂 File Management System (Java)

## 📌 Project Overview
The File Management System is a Java-based application designed to help users efficiently manage and search files within a directory. 
It reduces manual searching time and improves file retrieval performance.

## 🎯 Objectives
- Quickly locate files using search functionality
- Support multiple file operations
- Improve user experience in managing large directories

## 👥 User Roles

### 🔹 Admin
- Add Admin
- Delete Admin
- View Users
- Delete User
- View Files
- Delete File
- View Download History

### 🔹 User
- Register & Login
- Search Files
- View Files
- Download Files

## 🛠 Technologies Used
- Java
- OOP Concepts
- File Handling

## ▶ How to Run the Project

1. Clone the repository:
   git clone https://github.com/JeyaPrawinRaj/File-Management-System.git

2. Open the project in any Java IDE (Eclipse / IntelliJ / VS Code)

3. Compile and run:
   MainApp.java 
   OR 
   FileManagementSystem.java
